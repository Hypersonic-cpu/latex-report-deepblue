\chapter{Overview}
\sectionlead{This template keeps the cover visually assertive while the body remains quiet, spacious, and suitable for long-form technical reports.}

\section{Design intent}
The visual system uses a dark navy foundation, a soft blue hierarchy, and a restrained yellow accent. The strong contrast is intentionally concentrated on the cover. Inside the report, color is limited to headings, fine rules, links, and lightly shaded table rows.

The page geometry is wider than many thesis defaults: the main text and tables use most of the A4 width while retaining enough margin for comfortable reading and printing. Body text uses a serif face, while headings and report metadata use a sans-serif face for a clean technical appearance.

\begin{insightbox}[Recommended use]
Use this template for research notes, architecture reports, experiment summaries, literature reviews, project plans, and internal technical documents. Keep body graphics restrained; let data and structure carry the emphasis.
\end{insightbox}
